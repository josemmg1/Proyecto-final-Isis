# Reuniones del equipo

Reuniones internas del equipo de Introducción (sin el equipo de Backend). Un archivo por reunión con el nombre AAAA-MM-DD-tema.md. Cada registro incluye:

- Fecha
- Asistentes
- Temas tratados
- Tareas asignadas (responsable y fecha límite)

Las actas de las reuniones con el equipo de Backend están en la carpeta `actas/`.
