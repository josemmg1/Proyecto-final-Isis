# Historias de usuario

Las historias están registradas como Issues en el repositorio del equipo de Backend con la etiqueta `historia-usuario`.

Formato de cada historia:

- Como [tipo de usuario] quiero [acción] para [beneficio].
- Criterios de aceptación (2 a 4): Dado [situación] cuando [acción] entonces [resultado esperado].
- Prioridad MoSCoW, estimación en puntos (dada por Backend) y autor.
